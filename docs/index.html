offset 0006SDE III

Async translation pipeline

A rate-limited synchronous REST integration was holding a 1.28M-item catalog translation hostage to API latency. I rebuilt it as a Spring Boot producer-consumer service over mTLS Kafka, with 1,000-record batches, dead-letter retries and idempotent upserts so any message can be replayed safely.

300× throughput over the per-record baseline; 1.28M items translated en-CA → fr-CA.

offset 0005SDE III

GraphQL serving with BatchLoaders

Interlink endpoints made one Cassandra read per record and blew the p99 SLO at peak. DGS BatchLoaders coalesce each request's lookups into batched, partition-local reads. When pods started OOMKilling, heap dumps showed payload growth rather than a leak, so the fix was heap, limits and autoscaling, not a code hunt.

p99 within SLO at 2× peak QPS, across five page types.
